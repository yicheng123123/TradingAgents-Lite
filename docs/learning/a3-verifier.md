# A3 Evidence Verifier 与有界恢复

Verifier 接收结构化提案、当前任务证据、实际入模引用和分区。它检查动作枚举、空引用、上下文成员、历史经验误用、版本、归属和截止时间。高波动时建议 Hold，Risk Manager 独立执行波动阈值。返回 passed、violations、error_code、repairable 和 suggested_action。

Citation Validity 表示引用对象、时点和权限符合规则。Citation Entailment 判断证据文字能否推出论点。当前实现返回 not_assessed，对关键事实仍需语义复核。

F1 可以重做一次 Analyst 或 Trader 的 JSON 与可修复引用，也可重试一次短暂失效的确定性工具。Memory 异常时可退回当前证据，这种情况单列为降级。未来数据、权限违规和步骤耗尽进入 Hold。已完成且有成功修复记录的案例才计为恢复。

Harness 保存 run_id、task_id、节点、工具、call_id、长度、延迟、Token、错误、重试与恢复状态。模型完整请求不进入轨迹。F0/F1 使用相同故障和任务，结构化正确率以实际输出尝试计数，引用正确率以报告引用计数。

6. 为什么 Verifier 通过后仍有风险门？
